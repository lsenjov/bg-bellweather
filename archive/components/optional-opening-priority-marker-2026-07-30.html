Former specification

One opening-priority marker was optional. It would break or rotate simultaneous opening conflicts only if a later procedure required it.

Replacement

On 2026-07-30, the marker became required shared state. Place it beside the randomly selected first opener at setup, then move it to the human player who placed the highest active Pecking Order bid. If no active bid remains, leave the marker with the existing first opener.
