Superseded

Former specification

Honeycomb Cooperative used a five-cell cluster on party boards, Pecking Order pieces, and scoring-card watermarks. The web application instead used a single hexagonal cell.

Replacement

Honeycomb Cooperative now uses one outlined hexagonal cell across the physical components and web application. The other five web emblems use their existing board-game artwork, giving every party one consistent shape across both play surfaces.
