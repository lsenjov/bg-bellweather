Method and limits

Each player ran the conservative example-agent policy in a detached process. Every round therefore contained four one-Leverage openings, four empty Pecking Order counterbids, and four Organise resolutions. Across the game the replay recorded 48 openings, 48 counterbids, 48 counterbid readiness actions, 48 Organise decisions, and 12 Election acknowledgments.

  • This was a strong end-to-end retention and replay smoke test, not a strategic balance test.
  • The shared policy repeatedly used the same Harbormouth-to-Cloverfield route and did not use Court, Rally, Smear, or Bellweather Centre.
  • Capacity-four retention was executed but not stressed because those districts were empty at each Election. Focused engine tests remain the evidence for a populated capacity-four draw.

End-of-game findings

  • Rule implementation confirmed: every Election recorded all fifteen non-Centre districts, including districts absent from all revealed cards. Bellweather Centre never appeared in a draw.
  • Reported defect resolved: Ironwood retained three of its six initial Support at Election 1 instead of remaining at six.
  • Centre remains untested strategically: Bellweather Centre was empty at the observed Election snapshots and at game end. This session confirms that no Centre draw was recorded, but it does not exercise preservation of non-empty Centre Support or provide evidence about the Centre's value as a jumping-off point or blocker.
  • Presentation question: 33 of the 45 district draw records were empty. Explicit empty draws improve auditability, but an Election bulletin may need compact grouping to keep the meaningful retained Support visible.
  • Agent-policy limit: identical conservative policies concentrated activity in four starting or adjacent districts. The next test should deliberately populate capacity-two, capacity-four, and capacity-six districts across the map and route Support through the Centre before every Election.

Setup failure before the completed game

An earlier ruleset-12 lobby completed all four Campaign Round 1 openings, then accepted two counterbids and two readiness actions before three player processes lost their controlling execution sessions. One bearer token had not been retained, so that seat could not reconnect through the public API. The attempt was abandoned without an Election, and no server-side credential workaround was used.

The replacement agents were launched as detached operating-system processes with private logs. All four remained alive through completion. Together with the earlier aborted API playtest, this repeats the same operational finding: an agent seat has no recovery path after its bearer token is lost. Long-running playtests must preserve both the process and credential before the host starts, or the test API needs a development-only reconnect mechanism.
