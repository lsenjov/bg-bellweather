Playtest agent API

The authenticated local contract shared by browser players and automated seats.

Index/Playtest agent API

Run the application locally at http://127.0.0.1:4317. Every seat receives an opaque bearer token. A command’s acting seat and timestamp come from the server; strict validation rejects unknown fields.

Ruleset 15

Start and connect

npm install
npm run build
npm start

# Development, with source packages and server reload
npm run dev

Create a table with POST /api/v1/games, or join one with POST /api/v1/games/join. Both responses include a session with gameId, a participant ID, and accessToken. Send the token as Authorization: Bearer ….

{
  "displayName": "Ada",
  "controller": "agent",
  "configuration": { "allowSpectators": true }
}

The host may start after two to six players have joined. Starting freezes the seat list and assigns the low-player doubled setup automatically when required. There is no auction timer configuration.

Command envelope

{
  "gameId": "uuid",
  "idempotencyKey": "agent-turn-0042",
  "expectedVersion": 17,
  "command": {
    "type": "game_action",
    "action": { "type": "pass" }
  }
}

expectedVersion is optional. Supplying it rejects a decision based on stale gameplay state. Reusing an idempotency key with identical content returns the first acceptance; different content is an error. Lobby commands are set_lobby_ready and host-only start_game. Public chat uses post_chat.

ActionRequired payload
open_partyfirmId and an unopened partyId. Submit only while the projected opening cursor names the seat.
operatepartyId and one play containing a matching operation and choice. The card resolves immediately. A second or third operate must use the same party, and only one play in the complete sequence may set claimBonus: true. The third card ends the action automatically.
finish_operateNo additional fields. Submit after the first or second resolved card to finish the sequence and pass play clockwise.
collectpartyId for an open party with a nonempty pile. The engine spends one Collection counter.
closepartyId for an open party whose Firm marker belongs to the acting player. Illegal on that player’s first Lobby turn of the year.
passNo additional fields.
set_election_readyBoolean ready, after phaseData.resultsRecorded is true.

Operation choices follow the selected family. Organise uses destinationDistrictId and optional sourceDistrictId; Rally uses districtId; Smear uses districtId and rivalParty; Court uses targetParty. Bonus-dependent optional fields are bonusDistrictId, bonusDistrictIds, bonusCourtParty, bonusSourceDistrictId, and bonusCourtSourceParty. Refetch after each accepted play so the next choice uses the resulting state.

{
  "type": "operate",
  "partyId": "night-parliament",
  "play": {
    "operation": "rally",
    "choice": {
      "operation": "rally",
      "districtId": "harbormouth"
    },
    "claimBonus": true
  }
}

An illegal choice returns illegal_action without consuming a turn or card. Refetch state after a version conflict or another seat’s action.

Phase and visibility

publicGame.phase is opening, lobby, election, or complete; phaseData carries the phase cursor. During Openings, turnSeatIds contains ABBA, ABCCBA, or the single clockwise orbit and may repeat a seat. During the Lobby, activeSeatId identifies the only acting seat. A non-null inProgressOperate gives the locked partyId, resolved operationCount, and whether the sequence has bonusClaimed; the active seat must either continue that Operate action or finish it.

Public state includes the year, Election number, Early Bird, public seat totals, party status and piles, Support, Court Support, Coalition Targets, Lobby actions, resolved Operations, year history, Election history, and chat. Opponents’ exact hands and New Year areas are hidden but their card counts are public. A seat projection adds that seat’s exact Operation inventories and all three ordered scoring slots. Previously revealed scoring slots remain public; future slots remain concealed.

After the game ends, every authenticated participant may fetch the complete event history and canonical final state. Random setup and Election draws are recorded, so replay never rerolls.

WebSocket resume

{
  "type": "authenticate",
  "gameId": "uuid",
  "accessToken": "opaque token",
  "afterSequence": 17
}

Omit afterSequence to receive a current snapshot. Include it to receive later projected events. Refetch state after an event when the agent needs current legality.

The reusable TypeScript client is in packages/testkit; a conservative runnable agent is in examples/playtest-agent.ts. BELLWEATHER_PLAYERS sets that agent’s host-only automatic-start target from two to six and defaults to two.
