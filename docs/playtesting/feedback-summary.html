Minimal and empty counterbids can capture disproportionately large Revolving Door packages, concentrating resources and enabling repeated oversized bids. Four-agent API game: a one-Leverage bid lifted one reserve to 25 Leverage; self-insurance repeatedly returned large openings and captured neighboring packages. Medium Investigate; this affected strategy throughout one complete game. Repeat with players explicitly valuing transfer position, and compare package sizes and reserve concentration after each round.
Uncapped, non-depleting operation bundles can create deterministic district takeovers without reducing the winner's future agency. Four-agent API game: one protected ten-card Foxglove opening converted a six-capacity district and denied an adjacent space, then returned through an empty self-bid. Medium Investigate burst size and recovery cost before changing limits. Deliberately construct one large bundle per player and measure counterplay, resolution time, and subsequent reserve strength.
Relative-seat modifiers can outweigh excellent map play. Four-agent API game: a maximum six-point base was cut to three in Election 1, another three-point base became zero, and one player lost five points cumulatively to modifiers. Low Keep under observation; one game's seat arrangement is insufficient for a balance change. Rotate the same agendas among seats or replay recorded map states with alternate seat orders.
Players can misread directional Coalition Targets as active coalitions, causing costly strategic errors. Four-agent API game: one agent overinvested in High Pastures after Foxglove redirected, because only Old Shell still targeted Foxglove. Medium Improve the web/API derived-state presentation before changing coalition rules. Display explicit active reciprocal pairs and test whether players still make the same mistake.
Protected openings and equal counterbid cancellation are strategically important but easy to apply asymmetrically by mistake. Four-agent API game: multiple agents expected an equal counterbid to cancel an opening; the counter cancelled while the opening survived. High Clarify the revealed-bid ledger and player aid. Ask new players to predict three equal-bid reveal outcomes before play.
Whole-map Election thinning now executes consistently while scoring remains limited to revealed objectives. Ruleset-12 API game: each Election recorded all fifteen non-Centre districts, never recorded Bellweather Centre, and thinned Ironwood from six Support to three at Election 1. High for implementation; low for balance Keep the rule. Run a targeted strategic test before judging how strongly it reopens the map. Populate all three district capacities, route Support through the Centre, and compare pre- and post-Election mobility.
Losing an agent seat's bearer token or controlling process can force a complete playtest restart. The first aborted API test and the discarded setup before the ruleset-12 follow-up both stalled after a seat became unrecoverable. High Require verified credential and process persistence before start; investigate a development-only reconnect flow. Kill and restore one agent process during a disposable lobby using the proposed recovery workflow.

Interpretation rules

  • “Three players disliked it” is feedback; “three players avoided it after the first round” is behavior.
  • Do not average away strong differences between new and returning players.
  • Record delight with the same care as friction.
  • Lower confidence when sessions share the same facilitator, group, or rules explanation.
