Design principles

Provisional tests for choosing between competing ideas.

Index/Design principles

These principles are a filter, not a feature list. Revise them when evidence shows that the game wants to be something else.

Provisional

Political context changes price

District capacity, a party’s Support and coalition target, its favored-operation bonuses, and its place in the Pecking Order should change the value, risk, or meaning of an influence bid. If the same bid is correct at every party, the targets are decoration.

Provisional

Every bid has a shadow

Bidding higher should surrender something: resources, information, flexibility, tempo, or safety. A number that only goes up is arithmetic, not tension.

Provisional

The state reads across the table

Players should see Support, free district spots, coalition targets, coalitions, party bonuses, and the Pecking Order without asking another player to narrate the board.

Provisional

Lower access redirects

A lobbying firm that acts later should inherit a new angle, constraint, or opportunity through the Revolving Door. Avoid compensation that makes later access strategically equivalent to acting first.

Provisional

Resolve faster than players deliberate

The interesting time belongs before commitment. Once choices are locked, resolution should be crisp enough that the table immediately sees the new problem.

How to use this page

  1. Name the two designs under consideration.
  2. Identify which principles meaningfully distinguish them.
  3. Write the smallest test that could reveal the difference.
  4. Record the result in the decision log.
