New board game idea

LadderBidding

A working desk for turning a name into a testable game—one explicit decision at a time.

Working title. Mechanics, theme, audience, and even the meaning of “ladder” remain open.

Start with the vision, write only the rules that are known, and keep every assumption visible enough to challenge at the table.
