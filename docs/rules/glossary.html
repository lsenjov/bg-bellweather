Glossary

Stable words reduce accidental rule changes.

Index/Glossary

Terms below are working labels only. Add a definition when the matching mechanic is selected; rename aggressively while the game is young.

Working vocabulary
Term Current use Status Avoid confusing with
Bid An offer or commitment made during a contest; exact form unresolved. Working label Payment, unless the winning bid is always spent
Contest One opportunity in which players may bid. Working label Round or turn
Ladder An ordered set of positions; what those positions represent is unresolved. Working label Score track
Position A player’s current place on the ladder. Working label Rank, score, or turn order
Rung One discrete position on a ladder. Working label Level or round

Style rule

Use one term for one game concept. If a component and an action share a name, change one before writing more rules.
