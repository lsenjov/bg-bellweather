Cards

Deck roles, information structure, and prototype counts.

Index/Cards

Reusable command cards are part of the current auction core. Their identities and quantities are concealed in players’ reserves, committed physically to bids, revealed together, executed, and transferred intact.

Decided

Command cards

Each command shows a target-category icon rather than naming one specific board target. Any target in that category defines what the command does there. The card or command type is committed during bidding; legal parameters are chosen when it executes.

The total command-card supply is fixed after setup. Every player begins the first prototype with an identical set, although the exact types and quantities remain open.

Card anatomy

  • Name states the card’s role, not its flavor alone.
  • Target-category icon is readable while held in a fanned hand.
  • Primary value is readable while held in a fanned hand.
  • Timing appears in the same location across a card family.
  • Rules text uses terms from the glossary.
  • Prototype cards use IDs so feedback identifies the exact card.

Inventory

Command cards are required, but their categories, effects, and identical per-player starting counts remain open.
