Operation tokens

Print at actual size on one A4 portrait sheet. Each token is exactly 25 mm square, and adjacent tokens share cut lines without gutters. The sheet contains six identical player supplies: four Organise, four Rally, four Smear, and two Court. The pastel stationery palette matches the lobbying-house components without assigning tokens to a house. Mount fronts on identical opaque board; no backs are included.
