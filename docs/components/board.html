Board

Spatial structure, tracks, and shared information.

Index/Board

The current mechanic requires distinct auction targets and a persistent Priority Order area. Target theme, effects, categories, and layout remain open.

Decided

Current board role

  • Give every auction target a unique, readable identity and command category.
  • Provide one public location for each opening auction and its ranked bids.
  • List every ordinary target in a persistent Priority Order area.
  • Allow the Priority Order area itself to receive an auction and resolve it first.
  • Swap one adjacent pair in the list for each command executed on the Priority Order area.
  • Use the same fixed starting order in every first-prototype session.
Archived prompt

Initial board questions

  • What information must be shared and ordered?
  • Does one ladder hold all players, or does each player have one?
  • Are rungs exclusive, shared, or capacity-limited?
  • Does position show progress, privilege, risk, price, or turn order?
  • Can the same information live on cards or a small track?
Superseded hypothesis

Initial ladder sketch

Draw six ordered spaces on one sheet of paper. Number them from bottom to top, leave room for every player marker on every space, and add no printed effects.

Reason: six spaces are enough to create relative position without making track length the main balance decision.

Specification checklist

  • Every space has a unique, readable identifier.
  • Player markers remain distinguishable when they share a space.
  • Direction of movement reads from every seat.
  • Any triggered effect is printed where it occurs.
  • The board shows state, not rules players must memorize.
