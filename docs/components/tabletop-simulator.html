The digital export uses the current component artwork and rules. Cards are cropped individually and grouped by their shared back; physical print-sheet margins, mirrored duplex placement and agent clip strips are omitted.

Build and validate

Run from the repository root. The exporter needs Node, Playwright with Chromium, and Python with Pillow. It uses the same browser installation as the print checks.

npm run tts:export
npm run tts:check
python scripts/test-publish-tts-assets.py
python scripts/test-generate-tts-loader.py

Generated files are in assets/tts/ and are not committed. manifest.json records image URLs, hashes, deck settings, card order and piece quantities. Images have content hashes in their filenames so future artwork exports can coexist with saved games.

The export contains all 151 cards in sixteen decks: common cards; six party suits; six firm suits; Hecate rewards; policies; and private priorities. It also includes the twelve opening markers, agent faces, reversible Gallery portraits, firm tokens, public markers, boards, twelve player folios, forty-eight private reminders, the score ledger and reference images. The printable suite remains available separately.

Publish to S3

Destination: s3://lsenjov-boardgame-bellwether/tabletop-simulator/, region ap-southeast-2. The default public image URL begins https://lsenjov-boardgame-bellwether.s3.ap-southeast-2.amazonaws.com/tabletop-simulator/. The AWS console bucket page is an administration page, not an image URL.

python scripts/publish-tts-assets.py
python scripts/publish-tts-assets.py --upload

The first command validates files and previews the upload without using AWS credentials. The second uses your configured AWS CLI identity, uploads only files listed in the manifest, and checks that each resulting image URL is accessible without authentication. It does not delete old assets or change bucket policies or ACLs.

Players need stable public HTTPS access to the images. If the bucket remains private, use your public delivery service, such as CloudFront. Regenerate and publish using the same delivery prefix in both commands:

npm run tts:export -- --base-url https://YOUR-PUBLIC-HOST/tabletop-simulator/
python scripts/publish-tts-assets.py --base-url https://YOUR-PUBLIC-HOST/tabletop-simulator/ --upload

Configuring that delivery service is separate from this export. An upload can succeed while public verification fails; in that case the images are stored but are not ready for other players. Do not use expiring signed URLs in saved games.

Import the component set

python scripts/generate-tts-loader.py

This writes assets/tts/import-bellwether.lua. After publishing the images, start an empty Tabletop Simulator table, paste the script into the Global scripting editor, and save it. Open the console and run lua Global.call("spawnBellwether"). The script imports the manifest's decks and pieces into a staging layout. Allow roughly 50 × 80 Tabletop Simulator units of clear staging space, plus margin for the pieces. Arrange and scale the components, then save the game. It does not run automatically on load. Run it only once on an empty table; saving/reloading the script resets its duplicate-import guard.

The importer has local generation and Lua syntax checks; its appearance and physics still need an in-game check. Manual import is also available below.

Import components manually

For each manifest deck, create a Custom Deck using face.url and back.url. Set Width and Height to the manifest grid dimensions and Number to its card count. Enable Back is Hidden and leave Unique Backs disabled. Each atlas reserves its final cell for the safe shared back. These images use normal row order, not physical duplex order. See the official Custom Deck guide.

Use Custom Board for the map and party boards, Custom Figurine for standees, and Custom Tile for flat pieces and references. Gallery portraits have an awake image.url and asleep imageSecondary.url; set both tile faces so flipping changes their state. Respect each object's manifest count. The custom-object API reference lists the corresponding image fields.

Use native coloured pieces for each party's unlimited Support supply. Give each player two Collection cubes, or four at two or three players. Use player hand zones for held cards and private zones for priorities and private reminders. Keep New Year cards concealed while their total count remains visible. Follow the rulebook for setup; importing artwork does not deal cards, place Support or automate firm powers.

Local checks verify asset inventories, image sizes, hashes, atlas geometry and hidden backs. A Tabletop Simulator session is still needed to check physical scale, readability, flipping and privacy before the first playtest.
