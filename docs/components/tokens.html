Representation rules

  • Shape and color should both distinguish player ownership.
  • Currency reserves and uncommitted command reserves remain physically concealed.
  • Opening bid values, opening command counts, and counterbid locations remain readable from across the table.
  • Opaque containers must conceal bid value from sight, bulk, and ordinary handling as far as practical.
  • Temporary markers leave the play area during cleanup so stale state cannot survive.

Superseded prototype prompt

The initial documentation shell proposed 10 undenominated coins or cubes per player before a bidding loop had been chosen. The first auction prototype replaces that prompt with 20 currency value per player in denominations of 1 and 5.

Questions before manufacture

  • Can one piece represent both position and ownership?
  • What mix of 1- and 5-value pieces permits flexible splitting without frequent change-making?
  • Do the containers conceal differences in token weight, sound, and bulk?
  • Which state is hard to remember without a marker?
