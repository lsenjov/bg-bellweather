# Party tracking boards

## Objective

Create six printable party boards that make each influence contest and its
public party state readable at the table.

## Format

- Three A4 landscape sheets.
- Two long horizontal party boards per sheet.
- A 5 mm print-safe sheet margin.
- One opening-bid area on each board.
- Two full-text, independently coverable bonus panels on each board.
- One overture track listing every other party plus an unpointed state.
- Reciprocal-overture coalition reminder without storing duplicate coalition
  state.
- Party-specific Shell and delayed-bonus reminders where required.
- No Support reserve area.

## Sheets

1. Honeycomb Cooperative / Old Shell Union
2. Foxglove League / Riverworks Party
3. Many Wings Coalition / Night Parliament

## Steps

1. Build the A4 print artifact and dedicated print stylesheet, using exact live
   bonus text and party-specific state.
2. Add the boards to the component documentation, decision log, player-aid
   specification, and changelog.
3. Validate document structure and print pagination, inspect all six boards,
   then obtain a fresh review and correct all high- and medium-severity
   findings.

## Validation

- Printing produces exactly three A4 landscape pages with two boards per page.
- Each party appears exactly once.
- Each party has one opening-bid area and two bonus panels.
- All twelve bonus titles and effects agree with the current rules.
- Each overture track contains the five other parties plus an unpointed state.
- Old Shell shows the Shell marker state.
- Night Parliament instructs players to mark the claiming bid for each delayed
  bonus.
- Text remains readable in color and grayscale.
- Documentation validation and whitespace checks pass.
