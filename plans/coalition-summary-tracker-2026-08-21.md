# Coalition summary tracker

## Goal

Add a compact physical summary of reciprocal coalitions to the A3 district map
without resizing or moving the district diagram. Supply one dedicated summary
token per party on the existing shared state-token sheet. The tracker mirrors
Coalition Targets; it does not create or alter coalition state and has no app
counterpart.

## Design direction

Treat the tracker as a small Bellweather register stamped into the map margin:
three interchangeable linked pairs, restrained black linework, and a compact
reserve. Use the established 14 mm party discs, saturated party colours, and
the six existing emblems so the summary reads at table distance without
instructional copy.

## Step 1 — Printable components

- Add a narrow vertical `Coalitions` tracker to the unused right margin of the
  existing 396 × 297 mm map.
- Give it three unnumbered pairs of 14 mm circular wells joined by bold lines.
- Add a boxed 3 × 2 reserve beneath the pairs with `No coalition` inside its
  border.
- Add one 14 mm colour-and-emblem Coalition summary token per party beside the
  existing Coalition Target marker on the A4 shared state-token sheet.
- Regenerate both affected PDFs and inspect them at full-page and detail scale.
- Commit the printable component change.

## Step 2 — Rules and component documentation

- Specify that Coalition Targets remain authoritative and that the acting
  player reconciles the summary after each card finishes resolving.
- Record setup, inventory, print layout, and public-information treatment in
  the current rules and component documents.
- Record the committed physical design in the decision log and changelog.
- Run document checks and the relevant print-export validation.
- Commit the documentation change.

## Step 3 — Independent review

- Have a separate agent review rules consistency, component completeness,
  accessibility, and print usability.
- Fix every high or medium issue and repeat review until none remain.
- Fix low documentation issues and report any other low issues before
  continuing.
- Commit each review-fix pass separately.
