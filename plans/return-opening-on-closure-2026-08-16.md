# Return opening markers on Closure

## Goal

Use the Firm opening marker itself as the physical open-state indicator. A
marker on a party means it is open; closing the party returns that marker to
its player. Remove the redundant Closed wells and markers.

## Step 1 — Rules and digital presentation

- Make returning the opening marker part of every Closure.
- Explain that returned markers show the public Closure count and cannot be
  reused during the same year.
- Align the glossary, examples, aids, and browser table presentation.
- Verify the application tests and documentation checks.

## Step 2 — Physical components and print assets

- Remove Closed wells from all six party workspaces.
- Remove the six Closed markers from the shared state sheet and rebalance the
  remaining public-piece layout.
- Update the component inventory, board specification, player folios, design
  decision log, and changelog.
- Regenerate the affected PDFs and run the full project check.

## Step 3 — Review

- Have a separate agent review the complete change.
- Fix all high and medium issues and repeat review until none remain.
- Fix any low documentation issues before handoff.
